# Itqan — إتقان

A calm daily Quran revision companion for huffaz, on the way of the Salaf.

- Daily portion in three sittings tied to the prayers (monthly khatm by default, or the Sahabah's seven ahzab)
- Juz map showing when each juz's turn comes
- Weak-spots notebook with surah/ayah, mistake type and fix methods
- Calm halaqah test plan, breathing, and authentic reminders
- English and Malayalam · works offline · installable on the home screen
